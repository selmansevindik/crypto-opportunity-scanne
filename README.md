# Crypto Opportunity Scanner

Saatlik çalışan, düşük piyasa değerli kripto varlıkları ön-elemeden geçiren ücretsiz GitHub Actions tarayıcısı.

## Sabit puan formülü

- Değerleme / Asimetri: %30
- Narrative / Katalizör: %22
- Teknoloji / Moat: %13
- Adoption: %10
- Tokenomics: %10
- Utility / Value Capture: %7
- Regülasyon / Survival: %5
- Likidite / Dağıtım: %3

## Temel filtreler

- Market cap <= 150 milyon USD
- Master Table coinleri hariç
- Tercihen son 2 yılda TGE
- Max X tercihen <5x; 5-10x ikinci kademe; 20x+ ağır ceza
- Düşük circulating / yüksek FDV ve ağır unlock baskısı cezalandırılır
- Yalnızca anlamlı değişikliklerde Telegram uyarısı

> Bu yazılım yatırım tavsiyesi üretmez. Otomatik skorlar aday keşfi/ön-eleme içindir; özellikle teknoloji, utility, regülasyon ve token unlock verileri için manuel doğrulama gerekir.
